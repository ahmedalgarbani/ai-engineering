# شرح الموشن — Motion explainer videos

Every lesson in the course has a 3Blue1Brown-style motion explainer: one picture that keeps evolving,
a short Arabic caption and a formula on top, and an Arabic voice-over for each step. The same
explainers play inside the app (lesson tab «شرح بالموشن») and render here to MP4.

- Engine: `../explainer.js` (scene primitives, deterministic timeline, in-app player)
- Lesson scripts: `../explainers/*.js` (one file per stage; authoring guide in `../explainers/README.md`)
- Voice durations for the app: `../explainer-voice.js` (generated by `plan`)

## Requirements

- Node 18+ and Python 3.8+
- Google Chrome installed (used headless to render frames)
- Internet access (Google Fonts, KaTeX from cdnjs, Microsoft Edge neural TTS through `edge-tts`)

```bash
cd video
npm install
python -m pip install edge-tts
```

## Build

```bash
node build.js all                 # tts → plan → render → assemble
```

| Step | Command | Output |
|---|---|---|
| Narration script | `node build.js script` | `out/narration_ar.md` (review the Arabic narration) |
| Voice-over | `node build.js tts` | `out/voice/*.mp3` (cached by text; reruns only add new lines) |
| Timeline | `node build.js plan` | `out/plan.json` + `../explainer-voice.js` (the app reads it) |
| Layout lint | `node lib/lint.js [C2.2,S3]` | script errors, off-canvas objects, overlaps, long captions |
| Visual QA | `node build.js stills C2.2` | `out/stills/<lesson>/*.png`, one per step |
| Render | `node build.js render --workers 5` | `out/explainers/*.mp4` (+ `.srt`), resumable |
| Join | `node build.js assemble` | full course + one video per stage |

`render --only C2.2,S3` renders selected lessons or stages. Finished videos are skipped unless their
timing, their own script, or the engine changed. The app plays the voice clips from `out/voice/`, so run
`tts` and `plan` once on a machine before using the voice in the app (otherwise it falls back to the
browser's Arabic speech synthesis with estimated timing).

## Final files (`out/`)

- `AI-Engineer-Motion-Explainers-Arabic.mp4`: all explainers, with chapters and an Arabic subtitle track
- `stages/*.mp4` (+ `.srt`, `.chapters.txt`, `.youtube.txt`): one video per stage
- `explainers/*.mp4` (+ `.srt`): one video per lesson

## Options

`--voice ar-SA-HamedNeural` (default) or any voice from `python -m edge_tts --list-voices | grep ^ar-`,
`--rate +10%`, `--fps 30`, `--crf 20`, `--workers 5`. After changing the voice or rate, run `tts`, `plan`
and `render` again (the clip keys include the voice and rate).

## Files

- `build.js`: CLI
- `lib/course.js`: loads course data + explainers into Node
- `lib/lint.js`: layout lint
- `lib/render.js`: headless frame capture piped into ffmpeg
- `lib/audio.js`: music bed, section whooshes, narration mix
- `lib/subs.js`: SRT from TTS sentence boundaries
- `page/explain.html`: render page (`Renderer.prepare(plan)` / `Renderer.seek(t)`)
- `tts.py`: edge-tts worker
